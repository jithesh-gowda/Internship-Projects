# 📊 Sales Performance Dashboard  

## 🚀 Overview  
This **interactive dashboard** provides insights into sales, profit, and revenue trends across different regions, months, and product categories.  
It helps businesses analyze performance, identify growth opportunities, and optimize strategies using data-driven visuals.  

## 🛠 Tools Used  
- **Power BI** (Data Visualization)  
- **DAX** (Data Modeling & Calculations)  
- **Power Query** (Data Cleaning)  
- **Python + Pandas** *(Optional - for preprocessing CSV data)*  

## 📂 Dataset  
- `Superstore_Sales.csv`  
  - **Columns:** Order Date, Region, Category, Sales, Profit, Quantity  

## 📌 Features  
- **Line Chart:** Tracks monthly sales trends  
- **Bar Chart:** Sales distribution across regions  
- **Donut Chart:** Sales breakdown by product category  
- **Slicer Filters:** Allows dynamic analysis by region & category    

## 💡 How to Use  
1️⃣ Open **Power BI Desktop**  
2️⃣ Import `Superstore_Sales.csv` into **Power BI**  
3️⃣ Format `Order Date` to **Month-Year** (`MMM-YYYY`)  
4️⃣ Create visuals: **Line, Bar, Donut, KPI Cards**  
5️⃣ Apply slicers for **Region & Category** filtering  
6️⃣ Customize with colors & labels for easy readability
