# Titanic Survival Data Analysis

## 📌 Overview
This project explores the Titanic dataset to extract meaningful insights using **visual and statistical exploration**. The analysis focuses on understanding survival patterns based on passenger features like age, fare, gender, and class.

## 🚀 Objective
- Perform exploratory data analysis (EDA)
- Use statistical and visual techniques to uncover patterns
- Document findings in Jupyter Notebook and PDF report

## 🛠️ Tools Used
- **Python** (Pandas, NumPy, Matplotlib, Seaborn)
- **Jupyter Notebook**
- **Markdown for documentation**

## 📊 Data Exploration & Visualization
Key techniques used in the analysis:
1. **Descriptive Statistics**
   - `.describe()` for basic statistics
   - `.info()` for dataset structure
   - `.value_counts()` for categorical distributions

2. **Data Cleaning & Processing**
   - Handling missing values in `Age`
   - Encoding categorical variables

3. **Visualizations**
   - Pairplot (`sns.pairplot`)
   - Heatmap (`sns.heatmap`)
   - Boxplots, Histograms
   - Scatterplots (`sns.scatterplot`)

4. **Observations**
   - First-class passengers had higher survival rates
   - Females were more likely to survive than males
   - Ticket fare positively correlated with survival

## 📝 Deliverables
- `titanic_analysis.ipynb` → Jupyter Notebook containing all analysis
- test.csv -> Dataset
- `README.md` → This documentation file

## 👀 Summary of Findings
- **Survival was influenced by ticket class and fare amount**
- **Females had a significantly higher chance of survival**
- **Passengers under 10 years old had slightly better survival rates**
- **Certain titles (Mr., Mrs., Miss) correlated with survival outcomes**
