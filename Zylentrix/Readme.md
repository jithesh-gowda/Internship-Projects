# 📊 Course Engagement & Feedback Analysis

## 📌 Overview
This project analyzes student engagement and feedback across various online courses. Using visualizations like **bar charts, heatmaps, scatter plots, and line charts**, the dashboard provides insights into **learning trends, demographic patterns, and course ratings**.

## 📂 Dataset
The dataset (`merged_file.csv`) includes **student demographics, course enrollment details, engagement metrics, and feedback ratings**.

### 🔹 Key Columns:
- **Student_ID**: Unique identifier for each student.
- **Name**: Student’s name.
- **Age**: Student’s age.
- **Gender**: Gender of the student.
- **Location**: City of enrollment.
- **Enrolment_Date**: Date of course enrollment.
- **Course_ID**: Identifier of the enrolled course.
- **Time_Spent_Minutes**: Total time spent on the course.
- **Completion_Percentage**: Course completion percentage.
- **Rating**: Course rating (1-5).
- **Feedback_Text**: Student feedback or review.

## 📊 Visualizations & Insights
### ✅ **Engagement Analysis**
- **Bar Chart** visualizing completion percentages per course.
- **Color gradient** highlighting performance levels dynamically.


### 📈 **Time-Based Patterns**
- **Line Chart** tracking enrollment spikes over time.
- **Scatter Plot** showing time spent vs. completion rate trends.

### 🌍 **Demographic Insights**
- **Map Visualization** displaying student distribution by location.
- **Stacked Column Chart** comparing course preferences across age groups.

## ✨ Interactive Features
- **Slicers:** Filter insights by location, course, or enrollment date.
- **Conditional Formatting:** Apply color variations based on engagement scores.
- **Drill-throughs:** Dive deeper into individual course or student performance.
