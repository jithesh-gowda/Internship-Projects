# 📊 Sales Summary using SQLite and Python

This is a beginner-friendly Python project that uses **SQLite**, **pandas**, and **matplotlib** to generate a basic sales report. It calculates total quantity sold and revenue per product and displays the results as printed output and visual charts.

---

## ✅ Features

- Auto-creates a SQLite database (`sales_data.db`) with sample product sales data.
- Calculates:
  - Total Quantity Sold per Product
  - Total Revenue per Product
- Outputs:
  - Printed summary in the terminal
  - 3 types of charts for easy understanding:
    - Bar chart: Revenue by product
    - Bar chart: Quantity sold per product
    - Pie chart: Revenue share by product

---

## 🧠 Learning Objectives

By completing this project, you'll learn how to:

- Use `sqlite3` to create and interact with a SQLite database
- Run SQL queries inside Python
- Load SQL results into a pandas DataFrame
- Visualize data using matplotlib charts
- Structure a small data analysis script from scratch

---

## 🛠️ Requirements

- Python 3.x
- Libraries:
  - `pandas`
  - `matplotlib`
